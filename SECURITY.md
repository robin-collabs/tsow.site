# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 0.2.x   | ✅        |
| < 0.2   | ❌        |

## Reporting a Vulnerability

Please **do not** open a public issue. Use GitHub's
[private vulnerability reporting](../../security/advisories/new) for this repository.

You can expect an acknowledgement within 7 days. TSOW is a static, browser-only
app with no backend, accounts or stored user data, so most reports will concern
dependencies or the build/deploy workflow.
